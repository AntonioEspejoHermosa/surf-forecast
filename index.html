Forecast options

Sunrise uses the standard solar horizon; dusk is the end of civil twilight. Shading follows these solar transitions, independently of forecast steps. Tap any six-hourly compass for the full wave components. Compasses show the primary swell (teal), wind sea (coral) and secondary swell (dashed). Each arrow starts at a point showing Period and direction FROM on a fixed 0–25 s scale. Arrow length increases with offshore Hs; a short base length keeps small systems visible. A + marker at the rim means the Period exceeds 25 s; the popup retains the full value. Component Period values are approximate: source mean periods (Tm01) are multiplied by the selected factor (default 1.4). This depends on spectrum shape and does not reconstruct the true peak. A supplied component peak period is used directly. The main forecast Period row keeps the original total-wave peak period. Arrows show wave travel. The shore line uses the forecast beach orientation. Each compass samples the first available forecast record in a six-hour interval; other rows retain every forecast time. Missing components remain unavailable. Component values come from the downloaded partition fields, including Copernicus IBI when selected in the downloader. Wave and tide shading share midnight-to-midnight day boundaries. Beach Hs is an estimate. Water temperature is a surface-skin proxy. Tides are model-relative, exclude storm surge and use a fixed −2 to +2 m axis.
